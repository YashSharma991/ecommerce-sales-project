# Ecommerce-sales-project
Data analysis project using SQL
📌 E-Commerce Sales Analysis (SQL Project)
📖 Project Overview

This project is a complete E-Commerce Sales Database System built using SQL.
It includes database design, table creation, data insertion, and analytical queries to extract meaningful business insights.

🗂️ Database Structure

The project consists of the following tables:

Categories – Product categories
Products – Product details with price & stock
Customers – Customer information
Orders – Order details
Order_Items – Products within each order
Payments – Payment transactions
⚙️ Tools & Technologies
SQL (MySQL)
Database Design
Data Analysis using SQL Queries
📊 Key Features / Analysis Performed

✔️ Basic Queries

Retrieve products, customers, and orders
Filter data (price > 1000, city-based customers)
Count and distinct operations

✔️ Intermediate Queries

Joins between multiple tables
Group By and Aggregations
Order analysis per customer

✔️ Advanced SQL Analysis

Total revenue per product
Top 3 customers by spending
Monthly revenue report
Category-wise sales
Most ordered product
Customer spending above average
Product ranking using window functions
